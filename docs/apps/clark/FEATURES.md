# Clark Features

## Core Features

### トップページ

- サイト名「Clark - UFO事件と人物」を表示する
- ヒーローセクションに短い説明文を置く
- 現在のMVPではケネス・アーノルド事件カードのみを表示する
- 各カードに以下を含める
- タイトル
- サブタイトル
- 年代
- 場所
- 短い説明文
- タグ
- 個別ページへのリンク
- 将来複数カードへ戻せる構造は残す

### 個別ページ共通構成

- 各事件ページはスクロールテリング形式にする
- 初期MVP導線は以下を中心にする
- `/clark/kenneth-arnold`
- `/clark/george-adamski` と `/clark/billy-meier` は既存ルートとして残すが、トップ導線からは外す
- 各ページは以下の順で構成する
- `Opening Scene`
- 大きなビジュアルを表示する
- 動画または3Dモデルを表示する
- 年代・場所・人物名を表示する
- `What Happened`
- 事件の概要を500〜800字程度で説明する
- 初見でも全体像がわかる文章にする
- `Scroll Story`
- スクロールごとに場面が進む
- 1セクション1場面で構成する
- 短い文章とビジュアルを組み合わせる
- `Person`
- 事件の中心人物を紹介する
- 経歴、証言、影響を簡潔に説明する
- `Object / 3D Model`
- UFOの3Dモデルまたは動画を表示する
- 回転、拡大、視点変更などを想定する
- 目撃証言や写真との関係を説明する
- `Why It Matters`
- UFO史における重要性を説明する
- その事件が何を生み出したかを書く
- `Believer View / Skeptic View`
- 信じる側の見方を示す
- 疑う側の見方を示す
- Clarkとしての中立的なまとめを入れる
- `Next Case`
- 次の事件ページへの導線を置く

### ケネス・アーノルド事件のスマホ展示

- スマホでは上スワイプで1画面ずつ進む縦型展示にする
- `01 Opening` は背景動画にタイトルと短いイントロを重ねる
- `02 What Happened` はマウントレーニア写真に概要文を重ねる
- `01 Opening` と `02 What Happened` は、背景が見える薄い glass panel を使い、本文の可読性を保つ
- `Scene 02 / Report` は1947年頃のアーノルド本人写真を背景に、East Oregonian、Nolan Skiff、Bill Bequette による初期報道の流れを見せる
- `Scene 03` のデータ説明は常時表示せず、`i` ボタンから上部の glass popup で開く
- `Full Video` は再生開始後に説明UIを消し、9:16映像全体をクロップせずに見せる
- `Believer / Skeptic` の代わりにケネス・アーノルドのトリビアカードを1枚ずつ表示し、実資料・実風景画像を背景にして左右スワイプで切り替える
- 一部のトリビアカードでは、サムネイルから資料画像を拡大表示できる
- トップページのケネス・アーノルド事件カードはカード全体をリンクにし、明示的なCTA文言は表示しない
- 最後はSpotify、Apple Podcasts、YouTubeのPodcast導線を主にし、Clark トップへ戻る導線を補助として残す
- Xなどで共有した時にケネス・アーノルド事件専用のOGP/Twitter Card画像が表示される

### 動画利用方針

- Clark本体の没入演出にはTikTok埋め込みを使わず、自前動画を直接掲載する
- TikTok埋め込みはページ下部の補助導線に限定する
- 自前動画は `autoplay` `muted` `loop` `playsinline` を基本とする
- `poster` 画像を用意する
- スマホでは軽量版動画を使う

### 将来拡張の前提

- 将来的には事件カード・人物カード・形状カードを追加できる設計にする
- ただし初期MVPでは、上記3事件ページの完成を優先する

## User Flow

1. ユーザーがトップページに訪問し、Clark の目的とケネス・アーノルド事件を知る。
2. ユーザーがケネス・アーノルド事件カードを選び、個別ページへ移動する。
3. ユーザーが `Opening Scene` と `What Happened` で事件の全体像をつかむ。
4. ユーザーが `Scroll Story` を読み進めながら、場面ごとの流れを体験する。
5. ユーザーが `Person` と `Object / 3D Model` を通じて人物と物証イメージを理解する。
6. ユーザーが `Why It Matters` と `Believer View / Skeptic View` を読み、文化的影響と論争点を把握する。
7. ユーザーが最後に Clark トップへ戻る。

## States

- 読み込み中: ヒーロー画像、動画、3Dモデルの読み込み中状態を表示する
- 成功: テキスト、ビジュアル、次ページ導線が正常に表示される
- 動画代替: 動画が再生できない場合は `poster` 画像または静止ビジュアルを表示する
- 3D代替: 3D表示が難しい環境では動画または静止画像にフォールバックする
- モバイル最適化: スマホでは軽量版動画を優先して表示する
- コンテンツ不足: ある補助素材が未用意でも、本文と主要ビジュアルだけで読了できる状態を保つ
- 導線維持: ケネス・アーノルド事件ページの最後から Clark トップへ戻れる
- 補助導線: TikTok埋め込みが読み込めなくても本編体験には影響しない
- エラー: メディア読み込み失敗時も本文とページ構造は崩さない

## Acceptance Criteria

- トップページでサイト名、短い説明文、ケネス・アーノルド事件カードが表示される
- 各カードにタイトル、サブタイトル、年代、場所、短い説明文、タグ、個別ページリンクが含まれる
- トップページは将来複数カードへ戻せる構造を残しつつ、現在はケネス・アーノルド事件のみを表示する
- `/clark/kenneth-arnold` `/clark/george-adamski` `/clark/billy-meier` の3ページが存在する
- 各事件ページに `Opening Scene` `What Happened` `Scroll Story` `Person` `Object / 3D Model` `Why It Matters` `Believer View / Skeptic View` `Next Case` が揃っている
- `What Happened` が初見ユーザーでも全体像を把握できる分量と内容になっている
- 本編演出の動画はTikTok埋め込みではなく自前動画で構成されている
- 自前動画に `autoplay` `muted` `loop` `playsinline` と `poster` が設定されている
- スマホで軽量版動画が使われる
- `Believer View / Skeptic View` において、断定ではなくバランスの取れた中立的整理が行われている
- ケネス・アーノルド事件ページから Clark トップへ戻れる
