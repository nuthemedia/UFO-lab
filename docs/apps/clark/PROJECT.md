# Clark Project

UFO事件と人物を、スクロールテリングで体験的に理解するためのWebサイト

## Purpose

Clark は、Wikipediaのような網羅的な事典ではなく、有名UFO事件を「体験的に理解する」ためのデジタル・ミュージアムである。

基本思想は、「UFO事件を情報ではなく体験として読む」である。

単なる情報整理ではなく、3Dモデル、短尺動画、スクロール演出、人物解説、論争点を組み合わせ、事件の空気を感じられる体験を提供する。

## Audience

- 有名UFO事件を初めて知る人
- 断片的な知識はあるが、事件の全体像や文化的影響をまとめて理解したい人
- UFO文化史を、年表や事典ではなく没入感のある体験として読みたい人

## MVP Scope

- 現在のMVP導線はケネス・アーノルド事件を中心にする
- トップページにはケネス・アーノルド事件カードを配置する
- ケネス・アーノルド事件ページは、スマホでもPCでも上方向のスワイプ、ホイール、キー操作で進む縦型展示として体験できる
- ジョージ・アダムスキー事件とビリー・マイヤー人物ページは既存ルートとして残すが、トップ導線からは外す
- 各ページで以下をバランスよく提示する
- 何が起きたとされているのか
- 誰が語ったのか
- なぜ有名になったのか
- どこが信じられたのか
- どこが疑われたのか
- UFO文化に何を残したのか
- 事件ごとの役割を明確に見せる
- ケネス・アーノルド事件: 現代UFO史の起点。「空飛ぶ円盤」という言葉が広まるきっかけ

## Out Of Scope

- Wikipediaのような網羅的な全事件データベース化
- 事件の真偽を断定すること
- 証拠の最終判定サイトとして設計すること
- 初期3件以外の大量追加を前提にした大規模事典UI
