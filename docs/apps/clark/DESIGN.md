# Clark Design

## UI Direction

Clark のデザインは、UFO事件を扱う「夜のデジタル・ミュージアム」を目指す。

- 黒背景を基調にする
- 白文字を中心にする
- アクセントカラーは控えめに使う
- SF的な空気は持たせるが、安っぽい宇宙感にはしない
- オカルト雑誌風ではなく、現代的なミュージアム展示に近い印象にする
- ただし、事件ごとに少しレトロな質感を入れてもよい
- スマホファーストで設計する
- 1画面に情報を詰め込みすぎない
- 余白を広く取り、1スクロールごとに場面が進む感覚を作る
- 長文ではなく、短いテキストと大きなビジュアルで読ませる
- カード、タグ、年表、引用風テキストを組み合わせる
- 事件の「資料性」と「没入感」を両立させる

Clark は、UFO事件を淡々と読むサイトではなく、事件の現場、証言、人物、物体、論争を順番に歩いていくような体験を目指す。

目指す印象は以下とする。

- 静か
- 深い
- 少し不穏
- 美しい
- 資料性がある
- スマホで最後まで読みたくなる

## Screens

### トップページ

- ルート: `/clark`
- ヒーローはシンプルにする
- 背景に薄い星空、ノイズ、レーダー風グリッド、または暗いグラデーションを使う
- 3つのカードを大きく見せる
- カードは写真・3Dモデル・動画サムネイルを使える設計にする
- カード、タグ、短い説明文で各事件の違いを直感的に伝える

### 個別ページ

- ルート:
- `/clark/kenneth-arnold`
- `/clark/george-adamski`
- `/clark/billy-meier`
- 冒頭にフルスクリーンに近い `Opening Scene` を置く
- 動画または3Dモデルを大きく表示する
- スクロールに合わせて、テキストとビジュアルが交互に現れる
- セクションごとに背景の濃淡やレイアウトを変え、単調にならないようにする
- 3Dモデル表示部分は、展示室の中央にオブジェクトが浮いているような見せ方にする
- `Believer View` と `Skeptic View` は左右比較、または上下カード形式にする
- 最後に `Next Case` カードを配置する

## Responsive Behavior

- スマホファーストで構成する
- スマホではカードを縦スクロールで並べる
- スマホでは短いテキストと大きなビジュアルを優先し、1セクション1メッセージの密度を保つ
- スマホでも動画や3Dモデルが主役に見えるよう、表示領域を十分に確保する
- PCではトップページを3カラムで見せ、比較しやすくする
- PCでは余白を広く取り、展示空間のような静けさを強める
- 個別ページではデバイスサイズに応じて、テキストとビジュアルの交互配置を自然に切り替える
- `Believer View` と `Skeptic View` は、スマホでは上下積み、PCでは左右比較を基本とする

## Motion And Effects

- カードホバー時に、軽い浮遊感や発光を入れる
- スクロールに合わせて、テキストとビジュアルが静かに現れる演出を使う
- セクション切り替え時は、背景の濃淡や光量がゆるやかに変化する程度にとどめる
- 3Dモデルは展示物を見る感覚を重視し、回転、拡大、視点変更を想定する
- ページ内演出動画は自前の `video` 要素で表示する
- TikTok埋め込みをメイン演出に使わない
- 動画には再生ボタンを目立たせず、環境演出として自然に流す
- 音声は基本なし
- ループ動画は短く、軽くする
- ヒーロー動画は暗めのオーバーレイをかけ、文字が読めるようにする
