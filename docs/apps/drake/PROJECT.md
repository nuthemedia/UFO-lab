# Drake Project

## Product Name

Drake

## Subtitle

宇宙人はいるのか、地球に来ているのか

## Concept

Drake は、宇宙人来訪説を感覚や信念だけでなく、ドレイクの式とベイズ推論を使って視覚的に考えるインタラクティブアプリである。

ユーザーはスライダーや証拠カードを操作しながら、宇宙人が存在する可能性、地球に来訪している可能性、UFO がその証拠になる可能性を段階的に考える。

## Core Questions

1. 宇宙人は存在するのか？
2. 存在するとして、地球に来ているのか？
3. UFO は、その証拠になるのか？

## Purpose

このアプリの目的は、宇宙人来訪説に対する答えを押しつけることではない。

目的は、ユーザーが以下を直感的に理解できるようにすることである。

- 宇宙人が存在することと、地球に来ていることは別の問いである
- UFO が未確認であることと、宇宙人由来であることは別の問いである
- 証拠の強さによって、来訪説への確信度は変化する
- 前提を変えると、結論も変わる

## Target Experience

ユーザーは、美しい星空を見ながら、自分の前提によって銀河の中の生命・知性・文明の光が変化することを体験する。

生命のある星は多く見えるかもしれない。しかし、知的生命になると減る。技術文明になるとさらに減る。地球に来訪しうる文明は、さらにごく少数になる。

そのうえで、UFO 証拠を見たときに、来訪説をどれくらい更新すべきかを考える。

## Audience

UFO や宇宙人来訪説に関心があり、断定ではなく前提と証拠の関係を視覚的に考えたいユーザー。

## MVP Scope

- ドレイクの式の前提をスライダーで調整できる
- 銀河の中の生命・知性・文明・来訪可能性を視覚的に段階表示する
- UFO 証拠カードを操作し、証拠の強さによって来訪説への確信度がどう変わるかを示す
- 結果は「あなたの前提では」「この設定では」など、思考実験として表示する

## Out Of Scope

- 宇宙人来訪説を断定的に肯定しない
- UFO をすぐ宇宙人の乗り物として扱わない
- 確率を客観的な最終回答として表示しない
- ユーザーの前提を正解/不正解として採点しない
- 実在 UFO 事件の結論を断定しない

## Expression Policy

アプリ内の結果は、必ず以下のように表現する。

- 「あなたの前提では」
- 「この設定では」
- 「この証拠をこの強さで評価すると」
- 「思考実験として」

避ける表現:

- 「宇宙人は来ている」
- 「宇宙人は来ていない」
- 「この確率が正解」
- 「科学的に証明された」

## Core Message

宇宙人はいるかもしれない。
しかし、地球に来ているかは別の問いである。
そして、UFO がその証拠になるかどうかは、証拠の強さによって変わる。
