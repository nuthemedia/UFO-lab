# Hoover データ品質確認計画

## 今回の目的

Hoover の本番 UI を作る前に、少数のページ単位サンプルでデータ品質を確認します。

今回の `/hoover/lab` は公開向けの完成 UI ではなく、HooverPage 型とサンプルデータが本番リーダーに耐えるかを確認するための簡易ビューです。

## 確認する品質観点

- 英語転写データがページ単位で意味を持つか
- 日本語全文訳が自然で、元英文の範囲を越えていないか
- 日本語要約がページ内容を過不足なく表しているか
- キーワード、トピック、人物、組織、地名が検索に役立つか
- 年代、資料番号、ページ番号が保持されているか
- 元 PDF と該当ページリンクに戻れるか
- OCR 品質や注意フラグがレビュー判断に役立つか
- 本番 UI に必要なデータ項目が不足していないか

## サンプルデータの扱い

初期サンプルは `data/hoover/sample-real-pages.json` に JSON 配列として保持します。

このファイルは本格取り込みデータではありません。PURSUE Release 1 の FBI `62-HQ-83894` 系 PDF URL を使いながら、英語転写、翻訳、要約、メタデータがどのように見えるかを確認する小型フィクスチャとして扱います。

サンプルには `warningFlags` を付け、手作業サンプルや AI/OCR 転写由来であることを UI から確認できるようにします。

## 将来の取り込み前提

将来的には以下のような英語転写済みデータの利用を検討します。

- Open Atlas / ufo-pursue-open-atlas
- UFO-USA
- その他、PURSUE Release 1 の OCR 済み・Markdown 化済みデータ

ただし、初期段階では外部データの全取り込みは行いません。HooverPage 型に合わせて、取り込み元の差異を吸収できるかを小さく検証します。

## `/hoover/lab` の役割

`/hoover/lab` は以下を確認するためのデータ品質ビューです。

- ページ一覧
- 簡易検索
- 詳細表示
- 日本語要約
- 日本語全文訳
- 英語転写テキスト
- キーワード、トピック、人物、組織、地名、年代
- 資料番号、ページ番号、OCR 品質、注意フラグ
- 元 PDF リンク、元 PDF の該当ページリンク
