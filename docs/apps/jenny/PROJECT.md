# Jenny - UFO REPORT ANALYZER Project

UFO目撃報告や調査報告の文章をJevで分析し、分類・数値・確率を中心とした日本語の結果を返すアプリ。

## Purpose

Jennyは、長いUFO目撃報告や調査報告を、比較可能な5つの評価へ変換するための分析ツールである。

自由文による長いAI解説ではなく、ハイネックの考え方を基礎にした分類とスコアを提示し、報告の奇妙さ、確からしさ、近接遭遇分類、説明困難性、証拠、フェイク兆候を一画面で直感的に把握できるようにする。

Jennyの評価は、文章から読み取れる情報を一定の基準で整理するための参考値であり、報告の真偽や異星人起源を断定するものではない。

## Audience

- UFO・UAPの目撃報告を手軽に整理して読みたい一般の愛好家。
- 複数の報告を共通の指標で比較検討したい調査者・研究者。
- 長い報告文から重要な評価軸を短時間で把握したい読者。

## Core Experience

1. ユーザーがUFO目撃報告または調査報告の文章を、大きなテキストエリアへ貼り付ける。
2. 「分析する」ボタンを押す。
3. JennyがJevを使って報告を分析する。
4. 5つの評価結果を、すべて日本語で単一の結果ビューに表示する。
5. 各数値を、左端を0として右方向へ伸びる水平バーでも可視化する。
6. 水平バーは、分析完了時に0から結果値まで滑らかに伸びる。

結果画面では長いAI解説文を生成せず、分類名、数値、確率を主役にする。

## Why Jev

JevはTypeSafe AIの評価モデルで、共有された入力を複数の型付き質問で評価し、自由文ではなくChoice、Score、Booleanとそれぞれの確率を返す。複数の質問を同じ入力に対して並列に評価できるため、分類・数値・確率だけを短く提示するJennyの体験に適している。

想定する対応関係は以下とする。

- Choice：近接遭遇分類の選択と、各候補の適合確率。
- Score：ストレンジネス、報告の確からしさ、証拠強度などの段階評価。
- Boolean probability：通常・既知現象では説明困難な報告として残る度合いや、フェイクを示唆する兆候の検出度。

実装にはAI SDK 7以降と `typesafe-ai/jev` を使用する想定だが、依存関係、質問形式、採点ルーブリック、APIレスポンス型は実装仕様を作る段階で確定する。

## MVP Scope

### Text Input

- 対象は、テキストとして貼り付けられたUFO目撃報告または調査報告。
- 1回の操作で1件の文章を分析する。
- 分析結果は日本語で表示する。

### 1. SP Classification

ハイネックのStrangeness / Probabilityをベースにした、最も重要な評価として結果画面の先頭に大きく表示する。

- `S | ストレンジネス`：報告内容の奇妙さを `0.0〜10.0` で表示する。
- `P | 報告の確からしさ`：文章内の整合性、報告条件、情報の具体性などから、報告の確からしさを `0.0〜10.0` で表示する。

表示例：

```text
SP分類
S｜ストレンジネス      8.7 / 10
P｜報告の確からしさ    6.2 / 10
```

### 2. Close Encounter Classification

次の候補から最も適合する分類を選び、分類名と適合度を表示する。

- `CE1 | 第一種接近遭遇`
- `CE2 | 第二種接近遭遇`
- `CE3 | 第三種接近遭遇`
- `近接遭遇に該当せず`

表示するパーセントは、JevがChoiceで返す選択肢別確率のうち、選択された分類の確率とする。Jevが別途返すモデル信頼度とは区別する。

表示例：

```text
CE2｜第二種接近遭遇    94%
```

### 3. TRUE UFO Score

通常現象や既知現象による説明を検討したうえで、説明困難な報告として残る度合いを `0〜100` で表示する。

これは「宇宙人である確率」や「異星人の乗り物である確率」ではない。

表示例：

```text
TRUE UFO度             78 / 100
```

### 4. Evidence Strength

報告を裏付ける証拠の強さを `0〜100` で表示する。複数目撃者、独立証言、写真、映像、レーダー、物理痕跡、同時代資料など、文章に記載された裏付けの有無を考慮する。

`P | 報告の確からしさ`が報告内容と報告条件の信頼性を見るのに対し、証拠強度は独立した裏付けの量と質を見る。両者を同じ指標として扱わない。

表示例：

```text
証拠強度               38 / 100
```

### 5. Fake Indicators

文章内部の矛盾、時系列矛盾、不自然な記述、創作や加工を疑う要素など、フェイクを示唆する兆候の検出度を `0〜100%` で表示する。

文章だけから真偽そのものを断定せず、人物の信用性を評価する指標としても扱わない。

表示例：

```text
フェイク兆候           14%
```

### Result Visualization

- 5つの評価項目を基本の結果として表示する。
- すべての数値を、数値表記と水平バーの両方で示す。
- バーの左端を0、右端を各尺度の最大値とし、CSSの幅をスコアに連動させる。
- 円グラフ、ゲージ、レーダーチャートは使用しない。
- 分析完了時に、バーを0から結果値まで左から右へ滑らかに伸ばす。

## Product Principles

- 長いAI解説文を生成しない。
- 分類、数値、確率を主役にし、一目で比較できるようにする。
- 入力言語にかかわらず、結果は日本語で表示する。
- AIによる参考評価であり、事実確認や調査の結論ではないことを明示する。
- TRUE UFO度を異星人起源の確率として表現しない。
- フェイク兆候から報告の虚偽や報告者の意図を断定しない。
- Pと証拠強度を別の評価軸として維持する。
- 視覚表現は水平バーに統一する。

## Success Criteria

- ユーザーが文章を貼り付け、1回の操作で分析を開始できる。
- 分析完了後、SP分類、近接遭遇分類、TRUE UFO度、証拠強度、フェイク兆候の5項目が表示される。
- SとPは `0.0〜10.0`、その他の数値は定義された `0〜100` の範囲を外れない。
- CE分類はCE1、CE2、CE3、非該当のいずれかになり、選択された分類の適合度を伴う。
- 各数値と水平バーが一致し、バーが0から結果値までアニメーションする。
- 長いAI解説文を表示しない。
- モバイルとデスクトップのどちらでも、単一の結果ビューの流れで主要評価を理解できる。
- 結果から真偽や異星人起源を断定できるような表現を使用しない。

## Out Of Scope

- 画像、動画、音声、PDFファイルのアップロードや解析。
- 外部データベース、ニュース、気象、航空情報などとの自動照合。
- 複数報告の一括分析。
- ユーザーアカウント、分析履歴の保存、共有機能。
- 報告の真偽、報告者の意図、異星人起源の断定。
- 長文の要約、解説、推論過程の表示。
- 円グラフ、ゲージ、レーダーチャートによる可視化。

## Future Considerations

以下はMVPには含めず、実装・検証後の候補として扱う。

- 情報が不足した報告を無理に採点しない「分析に必要な情報が不足」判定を、5項目の前段となる内部ゲートとして設ける。
- 「複数目撃者」「物理痕跡」「時系列矛盾」など、固定語彙による短い根拠タグを追加する。
- 評価基準とJevの質問セットをバージョン管理し、モデルやルーブリック変更によるスコア差を追跡できるようにする。
- 既知事件と人工的な境界事例から検証用データセットを作り、表示値を公開前に校正する。
- 目撃者の個人情報を考慮し、Pro以上へ移行する場合はAI GatewayのZero Data Retention採用を再検討する。
