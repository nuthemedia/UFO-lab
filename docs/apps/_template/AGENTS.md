# Template Only

This directory is only a scaffold for app planning docs.

Do not use these files as an app specification. Do not implement an app from `_template`.

When planning a new app, copy this structure into `docs/apps/{app-slug}/`, fill each document with app-specific decisions, then implement from that app directory.

For an experiment under `app/experiments/`, copy only `AGENTS.md` and `PROJECT.md` (lightweight tier, see root `AGENTS.md` section 5). Add the remaining docs when the app graduates out of experiments.

For implementation, read the target app's `AGENTS.md`, then the docs it lists.
