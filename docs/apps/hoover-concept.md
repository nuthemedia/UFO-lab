# Hoover - FBI UFO記録ビュアー コンセプト

## 目的

Hoover は、PURSUE Release 1 に含まれる FBI 本部ファイル `62-HQ-83894` 系資料を対象にした、日本語スマホ向けの FBI UFO 記録ビュアーです。

対象は、いわゆる Flying Discs / UFO 関連の FBI 行政記録です。英語の古い公文書を、日本語ユーザーが検索し、読み、必要に応じて元 PDF で確認できる状態にすることを目的とします。

## Ruppelt との関係

Ruppelt は PURSUE 全体の資料カード・インデックスです。どの資料があり、どの公開状況なのかを確認するための入口として扱います。

Hoover は、その中でも FBI `62-HQ-83894` 本文をページ単位で読むための専用リーダーです。資料全体の発見ではなく、本文の検索、要約確認、翻訳確認、元 PDF への戻りやすさを重視します。

## 編集方針

Hoover は陰謀論的な演出や「宇宙人の証拠」を強調するプロダクトではありません。

古い FBI 行政記録を、次の順番で扱いやすくするアーカイブ・ビュアーです。

1. 日本語で探す
2. 日本語で読む
3. 英語転写を確認する
4. 元 PDF の該当ページを確認する

## 補助情報の扱い

Hoover で表示する日本語訳、要約、キーワード、人物、組織、地名、年代などのメタデータは、元資料そのものではありません。AI、OCR、VLM、手作業整理を含む補助情報として扱います。

UI では必要に応じて以下の注意を表示できる設計にします。

- この日本語訳は AI/OCR 転写をもとにした補助情報です。
- 正確な引用・判断には元 PDF を確認してください。
- 判読不能箇所や黒塗り部分は補完しないでください。
- OCR や転写に存在しない内容を追加しないでください。

## 将来像

将来的には、FBI `62-HQ-83894` のページ単位データに対して、英語転写、日本語全文訳、日本語要約、キーワード、トピック、人物、組織、地名、年代、元 PDF リンクを保持します。

本番 UI では、検索結果セットをスマホで読みやすいカルーセル型の詳細ビューとして扱う予定です。ただし、初期段階では本番 UI よりもデータ品質の確認を優先します。
