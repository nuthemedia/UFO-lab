# バイオリズムマシン Features

## App Overview

- アプリ名: `バイオリズムマシン`
- 英字サブタイトル: `COMPUTER BIORHYTHM`
- 目的: 1980年代風のコンピューター占い機体験をWebで再現する。
- バイオリズムは疑似科学・娯楽として扱う。
- 医療・健康判断には使わない。

## MVP Features

- スタート画面
- 診断メニュー選択
- テンキーによる生年月日入力
- 当日のバイオリズム診断
- 2週間のバイオリズム表示
- ふたりの相性診断
- 当日の相性診断
- プリントボタンによるプリントアウト風の結果表示
- もう一度診断
- 娯楽目的であることの注意表示
- 最下部に `UFO Lab Tokyo Experiments` のブランドサイトリンクを表示する。
- XなどでURL共有された時に、専用のカードサムネイルが表示される。
- faviconはUFO Lab Tokyo既存の `/icon.svg` を流用する。
- 初期入力欄は空欄から始める。
- SOUNDは初期状態でONにする。ただしブラウザ制約により、実際の発音は最初のユーザー操作後に開始する。

## Diagnosis Menu

MVPでは以下の4メニューを実装する。

- 今日のバロメーター
- 2週間バイオリズム
- ふたりの相性
- 当日の相性

`男女の出生率` は元マシンに近い要素として存在するが、現代のWebアプリでは扱いにくいためMVPでは実装しない。

## Biorhythm Calculation

生年月日から対象日までの日数 `t` を求め、以下の3つのリズムを計算する。

- 身体リズム: 23日周期
- 感情リズム: 28日周期
- 知性リズム: 33日周期

計算式:

```js
physical = Math.sin((2 * Math.PI * t) / 23)
emotional = Math.sin((2 * Math.PI * t) / 28)
intellectual = Math.sin((2 * Math.PI * t) / 33)
```

表示時は `-100` から `+100` のパーセントに変換する。

## Compatibility Calculation

2人分の生年月日を入力し、今日時点の身体・感情・知性の差から簡易的に相性スコアを出す。MVPでは簡易実装とする。

- 各リズムの差が小さいほど相性が高い。
- 身体・感情・知性それぞれの相性を出す。
- 3つの平均を総合相性にする。
- スコアは `0` から `100` で表示する。

## UI And Experience Requirements

詳細な見た目は `DESIGN.md` で定義する。FEATURESでは、実装に必要な画面要素と操作要件だけを扱う。

- スマホ優先で操作できる。
- 小型Web筐体風レイアウトを使う。
- 上部大型パネルは作らない。
- 小さなタイトル帯を表示する。
- 黒いCRT風表示エリアを表示する。
- スタート画面ではCRT内にアプリ名、3本のデモ折れ線グラフ、短い説明を表示する。
- スタート画面と2週間バイオリズムのグラフには `P: BLUE`、`E: RED`、`I: YELLOW` の凡例を表示する。
- 診断結果は基本的にCRT内に表示する。
- 診断メニューを表示する。
- 生年月日はテンキーで入力する。
- 日付は `YYYYMMDD` の8桁で入力し、存在しない日付は診断へ進ませない。MVPでは8桁入力時にも簡易チェックを行う。
- プリントボタンを押した時だけ、プリント口から紙が出るように表示する。
- プリントアウトの文言はカタカナ中心にし、感熱紙の印字に見えるようにする。
- `もう一度` はスタート状態へ戻り、再診断には再度100円投入風の演出を通る。
- `start`、`coin`、`analyzing`、`result` 中は、診断メニューボタンから直接別診断へ進ませない。
- 画面文言はカタカナ中心にする。
- 操作用のボタンは物理ボタン風にする。

## Later Enhancements

MVP後に追加・強化する候補。

- CRT走査線
- 点滅カーソル
- 文字送り演出
- 紙が出てくる演出

- 紙の質感

## Not Implemented In MVP

- DB
- API
- ログイン
- ユーザー保存
- 課金
- 画像素材を使った筐体再現
- 医療・健康アドバイス
- 妊娠・出生に関する診断
- 本格的な占星術・運命診断

## Completion Criteria

- スタートできる。
- 診断メニューを選べる。
- テンキーで生年月日を入力できる。
- 当日のバイオリズムをCRT内で見られる。
- 2週間バイオリズムをCRT内で見られる。
- 2人分の生年月日で相性診断できる。
- プリントボタンを押すとプリントアウト風の結果が出る。
- もう一度診断できる。
- 結果表示後に別診断を行う場合は、再度スタート画面と100円投入風演出を通る。
- URL共有時のXカードに、バイオリズムマシン専用サムネイルが表示される。
- スマホで操作しやすい。
- 後からデザインと演出を追加しやすい構造になっている。
