# バイオリズムマシン Design

## Design Concept

- 1980年代ゲームセンターのコンピューター占い機／バイオリズム診断機をモチーフにする。
- 80年代初頭のアーケード機らしく、滑らかな現代Web UIよりも、硬いパネル、少ない色数、発光するCRT文字を優先する。
- 小型のWeb筐体をスマホ上で操作しているような体験にする。
- レトロ未来感、CRTモニター、カタカナ中心の表示、物理ボタン、プリントアウトを主要な記号にする。
- 現代的なヘルスケアアプリにはしない。
- 写真の筐体を完全再現するのではなく、スマホで操作しやすい形に再構成する。

## Layout

スマホ優先で、上から以下の順に配置する。

1. 小さなタイトル帯
2. CRTモニター風の表示エリア
3. 診断メニュー
4. テンキー入力エリア
5. プリンター口
6. プリントアウト風エリア

上部の大型説明パネルは作らない。操作性を優先し、タイトル帯は小さくする。

## Cabinet

- 白または少し黄みのある白の縦長筐体にする。
- 少しだけ立体感を出す。
- 角はやや丸めるが、現代的に丸くしすぎない。
- 赤・黄・青などの細いアクセントラインを入れる。
- 操作しやすい余白を確保する。
- スマホ画面内で縦に収まる構成を優先する。
- 画像素材は使わず、HTML/CSSで表現する。
- 筐体全体を1枚画像にしない。

## Title Bar

表示内容:

- `バイオリズムマシン`
- `COMPUTER BIORHYTHM`

方針:

- 黒い小型サブCRT表示風にする。
- 大きな看板パネルにはしない。
- 上部で画面を占有しない。
- 80年代業務用機のラベル感と、初期デジタルゲーム機のマーキー感を出す。
- `バイオリズムマシン` はサブCRT内の疑似デジタル表示として大きめに表示する。
- `COMPUTER BIORHYTHM` は同じサブCRT内の小さな機種名表示として残す。
- 文字には走査線、硬い1px系ハイライト、発光感を入れ、80年代初頭ゲーム機のデジタル表示に寄せる。
- `バイオリズムマシン` はタイトルらしく黄橙系の発光色にし、メインCRTの緑文字と差をつける。
- 紫、ピンク、赤、黄などの派手な色は全面背景ではなく、細いアクセントラインとして残す。

## CRT Monitor

黒いCRT風の表示エリアを作る。

- 黒背景にする。
- 文字色は緑、橙、白系を使う。
- 画面文言はカタカナ中心にする。
- 走査線、点滅カーソル、軽い発光感を使う。
- スタート画面はゲームのアトラクト画面に寄せ、`PRESS START` を目立たせる。
- スタート画面のグラフは文字と入力待ち文言の下に、画面幅いっぱい近くで表示する。
- スタート画面と2週間バイオリズムのグラフには `P: BLUE`、`E: RED`、`I: YELLOW` の凡例を入れる。
- グラフはCRT内の横幅を広く使い、線の上下が切れないようにする。
- 長文を入れすぎない。
- 1画面あたりの情報量を少なくする。
- スタート画面では、CRT内に `バイオリズムマシン`、3本のデモ折れ線グラフ、短い説明、START促しを表示する。
- 診断結果は基本的にCRT内へ表示する。外側に別カードの結果パネルを作らない。

表示例:

```text
バイオリズムマシン
SYSTEM READY

スタート ボタン ヲ
オシテ クダサイ
```

```text
シンダン ヲ
エランデ クダサイ
```

```text
データ ヲ
ケイサン シテイマス

ANALYZING...
```

## Buttons And Control Panel

物理ボタン風の操作パネルにする。

- スマホで押しやすい大きさにする。
- タップ領域を広めにする。
- 押したときに少し沈む見た目にする。
- テンキーはわかりやすく配置する。
- 決定、戻る、クリアを用意する。
- 現代的なフラットボタンにしすぎない。
- 生年月日入力はネイティブdate inputではなく、筐体のテンキーで `YYYYMMDD` を入力する。
- 日付入力欄は初期空欄にし、存在しない日付はエラー表示して診断へ進ませない。
- 操作部は黒いアーケード操作板風にし、ボタンは硬い段差のある直方体寄りにする。
- スタート操作では、課金ではない演出として `INSERT 100 YEN`、`COIN IN`、`CREDIT 1` の短い状態変化を入れる。
- `もう一度` はスタート画面へ戻し、再プレイには再度100円投入風の演出を必要にする。
- メニューボタンは `menu` / `input` 中だけ診断選択として有効にする。`start`、`coin`、`analyzing`、`result` 中は、別診断へ直接進ませない。

テンキー例:

```text
[1] [2] [3]
[4] [5] [6]
[7] [8] [9]
[戻る] [0] [決定]
```

## Diagnosis Menu

FEATURES.md のMVPに合わせて、以下の4メニューを表示する。

- 今日のバロメーター
- 2週間バイオリズム
- ふたりの相性
- 当日の相性

ボタン上は読みやすさ優先で漢字かな混じりでもよい。CRT画面内ではカタカナ中心にする。

## Printout

診断結果は、下部から紙が出てくるように見せる。

- 診断完了直後は紙を出さない。
- `プリント` ボタンを押した時だけ、プリント口から下に向けて紙が出る。
- 紙の排出は一瞬ではなく、約1秒程度かけて段階的に出す。
- 白から少し生成りの紙にする。
- 黒より少し薄い感熱紙印字色を使う。
- レシート風、感熱紙風、ドットプリンタ風の印象にする。
- 細長い紙として表示する。
- 少し古い印刷物の雰囲気を出す。
- 表示文言はカタカナ中心にする。
- 細い横方向の印字ムラと軽いドット感をCSSで加える。
- ただし読みやすさを優先する。

プリントアウト部分は、CRTよりも読みやすくするが、MVPではカタカナ中心のサーマルプリンター風に寄せる。

## Footer Link

- 筐体最下部に `UFO Lab Tokyo Experiments` を中央寄せで表示する。
- リンク先は日本語ブランドサイト `/` とする。
- 診断UIより目立たない小さな銘板風にする。
- 外部リンク扱いにはせず、同一タブで遷移する。

## Share Thumbnail And Icon

- XなどでURLが共有された時のカードサムネイルを用意する。
- サムネイルは固定画像とし、ユーザーの診断結果は反映しない。
- 画像サイズは `1200x630` を前提にする。
- 見た目はトップのCRT画面をベースにし、白い筐体、黒いCRT、`バイオリズムマシン`、3色デモグラフ、`PRESS START`、`UFO Lab Tokyo Experiments` を含める。
- faviconはバイオリズム専用に作らず、UFO Lab Tokyo既存の `/icon.svg` を流用する。

## Color And Texture

- 筐体: 白、少し黄みのある白
- 画面: 黒
- 文字: 緑、橙、白
- アクセント: 赤、黄、青
- 紙: 白から少し生成り
- 背景: 暗め、または淡いグレー

最初の実装では、汚れや黄ばみは軽めでよい。過度にリアルな古び表現より、操作性と読みやすさを優先する。

## Typography

- CRT画面はドット文字・モノスペース風にする。
- CRT画面はカタカナ中心にする。
- プリントアウトは読みやすいモノスペース風にする。
- タイトルは少し太めにする。
- 文字サイズはスマホで読みやすくする。
- 日本語が読みにくくなりすぎるフォント指定は避ける。

## Motion And Effects

MVPでは軽い演出に留める。

- CRT走査線
- 点滅カーソル
- 診断中の `ANALYZING` 表示
- 紙が出てくるプリントアウト演出
- ボタン押下時の沈み込み
- 短い電子音
- SOUND ON / OFF

演出は長すぎないこと。診断中の待ち時間は1秒程度でよい。

## Sound

Web Audio APIで、音源ファイルなしの短い電子音を使う。

音の種類:

- スタート音
- ボタン音
- 決定音
- エラー音
- 診断中の短いピコピコ音
- プリントアウト時の短いジジジ音
- 結果表示時の短い成功音

注意点:

- 音は控えめにする。
- SOUND ON / OFFを用意し、初期状態はONにする。
- スマホ対応のため、最初のユーザー操作後にAudioContextを開始する。
- 音が出なくても診断機能に影響しない。

## Responsive Behavior

- スマホ優先で作る。
- 片手で操作しやすくする。
- ボタンを小さくしすぎない。
- 画面上部に説明を詰め込みすぎない。
- プリントアウト結果が読めるようにする。
- PC表示では中央に筐体を置く。
- PCでは背景に余白を持たせる。

## Avoid

- 現代的なヘルスケアアプリ風
- きれいすぎるカードUI
- 上部の大型説明パネル
- 写真の筐体を1枚画像にして重ねる実装
- 操作ボタンが小さすぎるUI
- 長すぎるアニメーション
- 読めないほど強いノイズ
- 医療・健康判断に見える表現
- 妊娠・出生に関する診断表現

## Completion Criteria

- アプリ名が `バイオリズムマシン` に統一されている。
- 1980年代のコンピューター占い機らしさがある。
- スマホで操作しやすい。
- CRT風表示エリアがある。
- 物理ボタン風UIがある。
- テンキーで日付入力できる。
- プリントボタンでプリントアウト風結果が出る。
- 上部大型パネルを作っていない。
- 画像素材なしで成立する。
- FEATURES.md の機能要件と矛盾していない。
