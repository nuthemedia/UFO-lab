# バイオリズムマシン Project

1980年代のゲームセンターにあったコンピューター占い機／バイオリズム診断機をモチーフにした、Web版プレイアブルモック。

Route: `/experiments/biorhythm`

## Purpose

スマホ上で、小型の業務用コンピューター占い機を操作しているような体験を作る。

現代的な健康アプリではなく、カタカナ中心の表示、CRT風の画面、物理ボタン風の操作、プリントアウト風の結果表示を通じて、レトロな娯楽機械として楽しめることを目的にする。

## Audience

- 1980年代ゲームセンター機、占い機、レトロコンピューター風UIを楽しみたい人
- UFO Lab Tokyo の本筋とは別に、実験ラボの遊び心あるプロトタイプを試したい人
- スマホで短時間に最後まで操作できる軽い診断コンテンツを触りたい人

## MVP Scope

- アプリ名は `バイオリズムマシン` とする。
- 英字サブタイトルを使う場合は `COMPUTER BIORHYTHM` とする。
- `/experiments/biorhythm` で、スマホ優先の小型Web筐体風レイアウトを表示する。
- スタート、診断メニュー選択、生年月日入力、結果表示、プリントアウト風表示、もう一度診断まで一通り操作できるプレイアブルモックを作る。
- 診断メニューは、当日のバイオリズム、2週間のバイオリズム表示、ふたりの相性診断を扱う。
- バイオリズムは、生年月日から対象日までの日数を使い、身体23日、感情28日、知性33日の周期で算出する。
- フロントエンドのみで実装し、DB、API、外部チャートライブラリ、画像素材は使わない。
- 後から詳細仕様、完成デザイン、効果音、演出を追加しやすい構造にする。

## Out Of Scope

- 医療、健康、妊娠、出生、生活判断に使える診断として扱うこと。
- 本格的な健康アプリ風の表現や、科学的根拠があるように見える表現。
- 完成版の筐体質感、紙質感、走査線、点滅カーソル、文字送り、紙送り、Web Audio API の効果音。
- SOUND ON / OFF、アーケード風装飾、その他の演出作り込み。
- サーバー保存、ユーザー登録、共有機能、履歴管理。

## Safety Notes

バイオリズムは疑似科学・娯楽として扱う。

画面内に「診断結果は娯楽目的です」「医療・健康判断には使用できません」という趣旨を小さく明記する。
