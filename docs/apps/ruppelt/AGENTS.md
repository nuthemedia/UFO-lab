# Ruppelt Agent Notes

Ruppelt is the PURSUE Japanese index for UFO Lab Tokyo.

Before changing Ruppelt behavior, UI, data, routes, or operations:

- Read this folder's `PROJECT.md`, `DESIGN.md`, `FEATURES.md`, and `DATA.md`.
- Keep the app focused on finding and reading official PURSUE / war.gov records in Japanese.
- Do not add interpretive document attributes to source records.
- Keep official files external; link to official URLs instead of hosting PDFs, images, audio, or video.
- Keep card data lightweight. Full OCR and translations belong under shared data and should be loaded only when needed.
