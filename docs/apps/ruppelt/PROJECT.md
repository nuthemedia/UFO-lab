# Ruppelt Project

Ruppelt is a mobile-first Japanese browser for U.S. government PURSUE / war.gov UAP records.

The app helps users:

- Search and filter PURSUE records in Japanese.
- Browse records as cards.
- Save records to check later.
- Open official files from the original source.
- Read available Japanese full-text translations without treating machine translation as an official source.

The official PURSUE metadata and files remain the source of truth.

## Current Release

Ruppelt V5.0 covers PURSUE Releases 01–07: 474 unique records, 278 Japanese full-text translations, and 135 official videos.
