# 中国UFO史年表 Design

## UI Direction

スマホで古い紙の年表を読んでいるような体験にする。読みやすさを最優先にし、UFO題材であっても近未来的な演出ではなく、紙資料をめくる感覚に寄せる。

キーワード:

- 古い紙
- ジャバラ折り

紙の質感は背景、カード、影、折り目、余白で表現する。トップ画面は添付ビジュアルを全面に使い、画像の市松模様は前処理で紙地に馴染ませた完成画像として扱う。表紙文字の可読性は紙パネルではなく、配置、文字色、影、画像位置、軽い明度マスクで解決する。年表本文では古い紙片を読む感覚を維持する。文字量が多くなる前提で、本文のコントラスト、行間、余白、タップ領域を優先する。

避けたい表現:

- 近未来的すぎるUFO UI
- ネオン過多
- 宇宙船ゲーム風
- 派手すぎるアニメーション
- 読みにくい装飾

## Screens

- トップ画面: タイトル、短いサブコピー、`1978-2023` の期間表示、紙テクスチャーを裏地にした全面ビジュアル、上向きの薄い矢印導線、UFO Lab Tokyoリンクを配置する。
- 年表画面: 上部に `中国UFO史` とトップへ戻るボタンを固定表示し、年代ジャンプ、分類フィルター、時代セクションごとの年表本文を配置する。
- 年表アイテム詳細: アイテムをタップすると、下から大きな紙のシートを出し、解説と出典を読みやすく表示する。

## Responsive Behavior

- モバイルを主対象にする。
- スマホでは縦スクロールで、ジャバラ折りの紙をたどるように読む。
- 年代ジャンプと分類フィルターは片手操作しやすい位置とサイズにする。年代ジャンプは現在位置を薄くハイライトし、`1947` はナビに出さない。
- 固定ヘッダーと分類フィルターは本文領域を圧迫しないよう、必要最小限の高さにする。
- フィルターは背景帯で囲わず、紙面上に軽く置く。
- デスクトップでは本文幅を広げすぎず、紙面の読みやすい幅に制限する。
- 装飾よりも本文、日付、分類、事件名、出典の判読性を優先する。

## Motion And Effects

- トップ画面から年表画面への遷移は、全面ビジュアルから紙の年表へ切り替わる控えめな動きにする。上スワイプ導線と矢印方向は一致させる。
- 詳細シートは下から紙が少し立ち上がる程度の短いアニメーションにする。
- 折り目、影、紙の重なりでジャバラ感を出す。紙面の縦線・横線はカードの下地に置き、カード上に重ねない。
- 年表カードは右上の控えめな折り目と軽い浮きで、タップできる紙片として表現する。折り目は通常時に主張させず、hover/focus時だけ少し見える程度にする。
- 参考ビジュアルは、紙や炭の質感を持たせず、黒茶1色のミニマルな線画にする。抽象記号だけにせず、場所、出来事、対象物が一目で分かる場面として描く。カードでは右側の小サムネイル、詳細シートでは本文前の大きな挿絵として使い、キャプションやクレジット文は表示しない。
- 派手な光、点滅、過度なパララックス、ゲーム風エフェクトは使わない。
