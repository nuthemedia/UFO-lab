# 中国UFO史年表 Project

中国におけるUFO研究会、重大事件、雑誌文化、ブーム、ネット文化を、スマホで直感的に読める年表として見せる。

## Purpose

中国UFO史を単なる事件一覧ではなく、改革開放後の科学熱、気功ブーム、民間研究会、雑誌『飞碟探索』、ネット時代、映画によるノスタルジー化までを一本の歴史として体験できる読み物にする。

各時代の出来事を時系列で追いながら、中国社会の空気、メディア環境、民間研究文化、ポップカルチャー化の流れを直感的に理解できるようにする。

## Audience

- UFO・UAP史を日本語で概観したい読者。
- 中国の大衆科学、雑誌文化、ネット文化、映画文化に関心がある読者。
- 個別事件よりも、社会背景を含めた歴史の流れをつかみたいスマホ閲覧者。

## MVP Scope

- スマホで読みやすい中国UFO史年表を提供する。
- 年表項目は、研究会、重大事件、雑誌文化、ブーム、ネット文化、映画によるノスタルジー化を含む。
- 各項目は時期、タイトル、短い説明、歴史上の位置づけを持つ。
- 最初の版では、全体を一本の時系列として読めることを優先する。

## Out Of Scope

- 個別事件の真偽判定や断定的な結論。
- 中国UFO史の網羅的データベース化。
- ユーザー投稿、投票、コメントなどの参加機能。
- 複雑な検索、絞り込み、地図、ネットワーク可視化。
