# 中国UFO史年表 Features

## Core Features

### 1. トップ画面

- タイトル「中国UFO史年表」を表示する。
- サブコピーを表示する。
- 対象期間として `1978-2023` を表示する。
- 添付ビジュアルを使った全面表示にする。
- 上スワイプ、または薄い矢印ボタンで年表画面へ遷移する。
- 下部中央に `UFO Lab Tokyo` へのリンクを表示する。

### 2. 年表画面

- 上部に `中国UFO史` とトップへ戻るボタンを固定表示する。
- 年代ジャンプを用意する。
- 年代ジャンプでは `1947` を表示せず、現在位置の年代をハイライトする。
- 分類フィルターを用意する。
- 年表本文は時代セクションごとに表示する。

### 3. 年表アイテム

- 年月日を表示する。
- 分類を表示する。
- 事件名を表示する。
- クリックできる紙片として、薄い折り目と浮きを表示する。
- 参考イラストがある項目では、カード右側に小さなモノトーン線画サムネイルを表示する。
- タップで大きな下からのポップアップを表示する。
- ポップアップには解説と出典を表示する。
- 参考イラストがある項目では、ポップアップ内に大きな線画だけを表示する。

### 4. フィルター

- `すべて`
- `研究会`
- `事件`
- `雑誌`
- `カルチャー`

## User Flow

1. ユーザーはトップ画面でタイトル、短いサブコピー、対象期間、UFO Lab Tokyoリンクを見る。
2. ユーザーは上スワイプ、または薄い矢印ボタンで年表画面へ進む。
3. ユーザーは固定タイトルと年代ハイライトを見ながら、時代セクションごとの年表本文を読む。
4. 必要に応じて年代ジャンプや分類フィルターで読みたい範囲へ移動する。
5. 気になる年表アイテムをタップし、解説と出典を確認する。

## States

- 初期表示: トップ画面を表示する。
- 年表表示: 年表画面で全分類のアイテムを時系列に表示する。
- フィルター適用中: 選択した分類のアイテムだけを表示する。
- 詳細表示中: タップした年表アイテムの解説と出典を下からのポップアップで表示する。
- 空表示: フィルター結果がない場合は、該当する年表項目がないことを短く表示する。

## Acceptance Criteria

- トップ画面にタイトル、サブコピー、`1978-2023`、全面ビジュアル、薄い矢印、UFO Lab Tokyoリンクがある。
- 上スワイプ、または薄い矢印ボタンで年表画面へ遷移できる。
- 年表画面の上部に `中国UFO史` とトップへ戻るボタンが固定表示される。
- 年代ジャンプと分類フィルターが使える。
- 年代ジャンプに `1947` が表示されず、現在位置に合わせて年代がハイライトされる。
- 年表本文が時代セクションごとに表示される。
- 各年表アイテムに年月日、分類、事件名が表示される。
- 年表アイテムをタップすると、解説と出典が大きな下からのポップアップで表示される。
- カードや詳細パネルに、内部管理用の確認中・注記・信頼度は表示しない。
- `すべて`、`研究会`、`事件`、`雑誌`、`カルチャー` の各フィルターが存在する。
