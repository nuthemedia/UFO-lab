# saucerpedia Fake Card

## 目的

saucerpedia の「UFOとフェイク」カードは、UFO写真・動画で使われることがある作為的な演出、加工、確認手段を整理し、初心者が「なぜ本物らしく見えるのか」「どこを確認すればよいのか」を短時間で理解できるようにするためのカードです。

特定の投稿者や目撃者を断罪するためのカードではありません。写真・動画は文脈、初出、撮影条件、加工の有無を確認してから判断する必要がある、という検証の入口として扱います。

## 一覧カード

一覧カードは、フェイクや検証方法の種類をざっと確認するための短いカードです。

含める項目は次のとおりです。

- 名称
- 英語名 / 別名
- カテゴリ: UFOとフェイク
- 種類
- 1行説明
- 関連タグ 2〜4個

一覧カードでは、細かい鑑定手順を入れすぎません。何が本物らしく見えやすいのか、または何を確認する方法なのかを優先します。

## 詳細カード

詳細カードは、フェイクの仕組みや確認方法を理解するための本文カードです。

含める項目は次のとおりです。

- 名称
- 英語名 / 別名
- カテゴリ
- 種類
- 30秒でわかる
- なぜ信じられやすいのか
- 見分けるポイント
- 関連用語

すべての項目を必須にはしません。確認方法カードでは「なぜ信じられやすいのか」よりも「何を確認するか」を重視します。

## 種類

初期実装では、次の種類を使います。

- 物理トリック
- 撮影トリック
- デジタル加工
- AI生成
- 確認方法

## 初期項目

初期実装では、次の項目を扱います。

- 模型UFO
- 吊り糸
- ミニチュア撮影
- 投げた皿・物体
- ガラス越し撮影
- 二重露光
- 合成写真
- トリック写真
- CGI / CG映像
- 画像加工
- 動画加工
- 切り抜き動画
- AI生成画像
- AI生成動画
- 初出確認
- 逆画像検索
- EXIF情報

## 書き方

- 断定的に「これは偽物」と決めつけない
- 目撃者や投稿者を嘲笑しない
- 作為、誤認、未確認を混同しない
- 写真・動画単体では距離や大きさが判断しにくいことを説明する
- 初出、文脈、メタデータ、連続性、光源、影、ピント、加工痕を確認する
- 関連用語として `検証`、`デバンキング`、`誤認`、`初出確認` へ接続する
