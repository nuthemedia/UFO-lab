# saucerpedia Term Card

## 目的

saucerpedia の用語カードは、UFO / UAP に関する言葉の意味をすぐ理解し、関連項目へ移動できるようにするための辞典カードです。

カードは、一覧表示用の短いカードと、詳細表示用のカード本文に分けます。すべての項目を必須にせず、用語ごとに必要な情報だけを表示します。

## 一覧カード

一覧カードは、用語一覧でざっと意味をつかむための短いカードです。80〜120字程度を目安にし、スマホで読み切れる情報量にします。

含める項目は次のとおりです。

- 用語名
- 英語名または別名
- 日本語訳
- カテゴリ
- 1行説明
- 関連タグ 2〜4個

一覧カードでは、情報を詰め込みすぎません。タイトル、分類、1行説明、関連タグが見えれば十分です。

## 詳細カード

詳細カードは、選択した用語をもう少し深く理解するための本文カードです。本文は400〜800字程度を目安にし、長文記事ではなくスマホで読みやすい辞典カードとして扱います。

含める項目は次のとおりです。

- 用語名
- 英語名
- 別名
- カテゴリ
- 主な時代
- 30秒でわかる説明
- 詳しく読む
- 関連用語
- 関連人物
- 関連事件

用語によって、関連人物や関連事件がない場合は表示しません。空欄を見せるのではなく、その用語に必要な情報だけを出します。

## 表示方針

- 用語の意味を先に伝える
- 断定しすぎず、用語の使われ方を説明する
- 初心者が次に読むべき関連項目へ進める
- UFO / UAP の古典文化と現代文脈を混同しない
- 検証が必要な用語は、事実と主張を分けて扱う
- 一覧は配列順ではなく `order` の学習順で表示する

## 学習順

用語カードは、初心者が読み進めやすい順に `order` を持ちます。1000番台から基本語、古典UFO、ハイネック分類、コンタクティ、アブダクション、研究・検証、政府調査、現代UAP、日本UFO史へ進む構成です。

- 1000番台: UFO、UAP、IFO、空飛ぶ円盤
- 2000番台: UFOウェーブ、フラップ、母船、近接遭遇
- 2100番台: 夜間発光体、昼間円盤、レーダー・ヴィジュアル、CE1〜CE3、S-P表
- 2200番台: 着陸痕、電磁効果、MIB
- 3000番台: コンタクティ文化
- 4000番台: アブダクションとハイストレンジネス
- 5000番台: 研究・検証
- 6000番台: 政府調査・資料公開
- 7000番台: 現代UAP
- 8000番台: 日本UFO史

## ハイネック分類系カード

J・アレン・ハイネックの分類に関わる用語は、単なる別名ではなく独立した用語カードとして扱います。

- 夜間発光体 / Nocturnal Light / NL
- 昼間円盤 / Daylight Disc / DD
- レーダー・ヴィジュアル / Radar-Visual / RV
- 第一種接近遭遇 / CE1
- 第二種接近遭遇 / CE2
- 第三種接近遭遇 / CE3
- S-P表 / Strangeness-Probability Rating

これらは `aliases` に略称や表記揺れを持たせ、`knowledge.ts` のID解決で人物カード、事件カード、既存の近接遭遇カードと相互に接続します。第四種・第五種接近遭遇は後年の拡張分類として扱い、この初期範囲には含めません。
