# saucerpedia Resource And Organization Card

## 目的

saucerpedia の「UFO資料・機関辞典」カードは、UFO / UAP 史に関わる政府調査、公開制度、研究団体、報告受付組織、資料アーカイブを整理し、初心者が「どの機関が何をしたのか」「どの資料や制度と関係するのか」を短時間で理解できるようにするためのカードです。

機関や資料を権威化するためではなく、UFO / UAP 史の中での役割、時代、関連人物、関連用語を中立的に整理します。

## 一覧カード

一覧カードは、資料・機関辞典の一覧や関連カードに表示する短いカードです。

含める項目は次のとおりです。

- 名称
- 英語名 / 正式名
- 種別
- 1行説明
- 関連タグ 2〜4個

一覧カードでは、詳細な組織史や報告書の内容を入れすぎません。何で知られる資料・機関なのかを優先します。

## 詳細カード

詳細カードは、資料・機関の役割と関連項目を理解するための本文カードです。

含める項目は次のとおりです。

- 名称
- 英語名 / 正式名
- 種別
- 主な時代
- 30秒でわかる
- 何をしたか
- 関連人物
- 関連用語

すべての項目を必須にはしません。関連人物や時代が明確でない場合は、表示しません。

## 種別

初期実装では、次の種別を使います。

- 政府調査
- 政府・公的機関
- 法律・公開制度
- 公開資料
- 民間団体
- 報告受付・航空安全

## 書き方

- 機関名や制度名を初心者にもわかるように説明する
- 「政府が認めた」「隠蔽した」といった煽りにしない
- 調査、公開制度、民間研究団体、資料アーカイブの違いを分ける
- 関連人物や関連用語へ進める導線を重視する
- 詳細な資料検索や全文閲覧は Ruppelt など資料系プロダクトへ接続する前提にする
