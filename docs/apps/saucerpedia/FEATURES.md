# 空飛ぶ円盤辞典 - UFO Encyclopedia Features

## Core Features

- `/saucerpedia` の辞典トップページ。
- 「空飛ぶ円盤辞典 / UFO Encyclopedia」の役割を伝えるヒーロー。
- トップから全カテゴリへ進めるR3Fの3D本スタックヒーロー。
- スマホ用の sticky 上部ヘッダー、固定下部ナビ、補助メニュー用ドロワー。
- トップのカテゴリ一覧末尾に表示する UFO Lab Tokyo 内の関連プロダクト導線: Kinichi、Kean。
- 用語、人物、事件、歴史、誤認、フェイク、資料・機関、体験モチーフの8カテゴリページ。
- `/saucerpedia/search` の横断検索ページ。
- 各カテゴリ辞典の検索入力。
- 各カテゴリ辞典のカテゴリまたは種別フィルター。
- 横断検索で用語、事件、人物、資料、誤認、フェイク、体験モチーフ、最小限の形状候補をカード表示する。
- 一覧カードから選択し、カード内の「詳細を読む」で詳細ビューへ移動する同一ページ内閲覧。
- 関連用語、関連人物、関連事件、関連プロダクトのIDベースリンク表示。
- `?item=` クエリによるカテゴリページ上の初期カード選択。
- 関連チップから対象カードの詳細を直接開く。
- 詳細ビュー内では、関連項目を常時見える関連チップとして確認できる。
- 詳細カード内で、関連資料・関連プロダクトを「出典・参考資料」として折りたたみ表示する。
- 詳細表示はポップアップ風ではなく、スマホでは詳細ページ風の大きな本文ビューとして表示する。
- 詳細ビューから「元の場所に戻る」で一覧カード位置へ戻る。
- 関連形状や「よくある見え方」など、独立カード化していない補助ラベルのチップ表示。
- MIB神話の流れを示す人物小特集カード。
- X共有用の大判OG画像と、画面に本文を追加しないmetadata SEO。

## User Flow

1. ユーザーはヒーローで saucerpedia がUFO / UAPの入口辞典だと理解する。
2. トップでは3D本スタックヒーローをスクロールし、現在表示中のカテゴリ導線から該当カテゴリページへ移動する。
3. スマホでは下部ナビから用語、人物、事件へ1タップで移動する。
4. ホーム、検索、全カテゴリ、Kinichi、Kean、UFO Lab Tokyo は上部ヘッダーまたはドロワーから移動する。
5. 各辞典で検索またはカテゴリ/種別チップを使い、一覧カードを絞り込む。
6. 一覧カードを選び、「詳細を読む」で右側ペインまたはスマホの詳細ページ風ビューへ移動する。
7. 関連チップから、用語・人物・事件・歴史・誤認・フェイク・資料・機関・体験モチーフの詳細を横断する。
8. 詳細内の関連チップから他カードへ移動し、必要に応じて「出典・参考資料」を確認する。
9. 詳細を読んだ後は「元の場所に戻る」で一覧の元位置へ戻る。

## States

- Success: 各辞典にカード一覧と選択中の詳細カードが表示される。
- Filtered success: 検索またはフィルターに一致するカードだけが表示される。
- Empty: 検索またはフィルターに一致するカードがない状態。現在は専用表示が未実装。
- Error: ローカル静的データのため、通常のAPIエラー状態は持たない。
- Loading: ローカル静的データのため、初期MVPでは明示的なローディング状態を持たない。
- Responsive: PCでは一覧と詳細を2カラム表示し、狭い画面では詳細を大きな本文ビューとして1カラム表示する。
- Mobile navigation: スマホでは固定下部ナビを用語・人物・事件の主要辞典に絞り、全カテゴリと外部導線はドロワーにまとめる。カテゴリページ上部の横ナビはスマホでは表示しない。
- Source disclosure: 正式な外部URLが未整備の項目は、関連資料カードまたは関連プロダクトを参考資料として表示する。
- Motion: カード操作は軽い沈み込み、境界色、淡い背景tintで反応を示す。詳細表示は短い `opacity + translateY` 程度に留める。
- Reduced motion: `prefers-reduced-motion` では移動アニメーションを止め、色と境界線の変化だけで状態を示す。
- Color wayfinding: カテゴリ識別色は現在地、選択状態、関連導線を補助するために使う。本文カードと詳細本文は不透明寄りに保ち、色だけで意味を伝えない。
- Share metadata: `/saucerpedia/opengraph-image` を共通の大判共有カードとして使い、各Saucerpediaページは `summary_large_image`、OG/Twitter画像、alt、keywords をmetadataで提供する。

## Acceptance Criteria

- `/saucerpedia` がビルドできる。
- `/saucerpedia` が導線中心トップとして表示され、抜粋カードや全カード一覧を抱えない。
- `/saucerpedia/terms`, `/saucerpedia/people`, `/saucerpedia/events`, `/saucerpedia/history`, `/saucerpedia/misidentifications`, `/saucerpedia/fakes`, `/saucerpedia/resources`, `/saucerpedia/motifs` が直接表示できる。
- `/saucerpedia/search` が直接表示できる。
- ページメタデータにタイトル、説明、canonical、OG、Twitterカードが設定されている。
- `/saucerpedia/opengraph-image` が1200x630の共有画像として生成され、トップ、カテゴリ、検索ページの `og:image` と `twitter:image` に使われる。
- X投稿用のSEO強化はmetadataに限定し、通常画面に新しい本文テキストやセクションを追加しない。
- トップには全カテゴリのカード型一覧が表示される。
- 8カテゴリページすべてが表示される。
- 各カテゴリ辞典で検索入力が動作する。
- 各カテゴリ辞典でカテゴリまたは種別フィルターが動作する。
- 横断検索でカテゴリフィルターと検索入力が動作する。
- 一覧カードを選択すると詳細カードが更新される。
- 一覧カード内の「詳細を読む」で詳細ビューへスクロールする。
- 詳細ビューの「元の場所に戻る」で一覧カード位置へ戻る。
- `/saucerpedia/terms?item=uap` のようなURLで、該当カードが選択状態で開く。
- 関連チップは表示名文字列ではなく、Saucerpedia 内の安定 `id` から解決したリンクとして表示され、対象カードの詳細へ接続する。
- 詳細ビューの関連チップと出典・参考資料パネルがモバイル幅で読める。
- Glassmorphism は上部ヘッダー、下部ナビ、ドロワー、検索/フィルターなどの操作レイヤーに限定し、本文カードと詳細本文は不透明寄りで読める。
- トップのカテゴリ一覧は8カテゴリを固有色で識別でき、カテゴリページのアクセント色も同じ理屈で切り替わる。
- トップの3D本スタックヒーローは、8カテゴリをBoxGeometryベースの本として表示し、巨大な単体表紙ではなく、薄い本が密に積層して通過する見え方にする。表紙、背表紙、ページ側面、上端・下端ページブロック、影が全冊で見える。表紙には軽量な `CanvasTexture` でカテゴリ名、英字ラベル、カテゴリ別モチーフを入れるが、テクスチャは表紙板の前面に限定し、上から見えるページ部分や小口は紙色で分離する。クロス装、革装、紙装、観測ノート、資料台帳などの個性を色、文字組み、罫線で出す。スクロール中は `layer = index - scrollIndex` のレイヤー順位ベースで本が重なり、active本が常に最前面に見える。次本は奥上から手前へ近づき、過去本は上側に残る。Canvasだけに重要なテキストを閉じ込めず、カテゴリ名・説明・導線はHTMLで表示する。`prefers-reduced-motion` では大きなスクロール連動を抑える。カテゴリページの一覧カードとは役割が分かれている。
- トップと一覧カードはスマホで過度に縦長にならず、概要は短く表示される。
- スマホで上部ヘッダー、下部ナビ、ドロワー、検索導線が操作でき、役割が重複しない。
- スマホの下部ナビは `用語 / 人物 / 事件` だけを表示する。
- スマホの上部ヘッダーでは `UFO ENCYCLOPEDIA` がホームへ戻れるリンクとして視認できる。
- スマホのドロワーは全カテゴリ、Kinichi、Kean、UFO Lab Tokyo、コピーライトを表示する。
- 個別辞典ページ上部には Kinichi / Kean リンクを表示しない。
- 各辞典の検索UIは `検索`、検索ボタン、`カテゴリー` ラベルを持つ。
- `選択中を読む` と詳細内の重なったカード表現は表示しない。
- `npm run verify:saucerpedia-knowledge` で未解決の関連IDがない。
- 関連プロダクト導線が表示される。
- モバイル幅でカードと詳細が重ならず読める。
