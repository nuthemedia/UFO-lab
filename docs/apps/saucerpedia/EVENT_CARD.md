# saucerpedia Event Card

## 目的

saucerpedia の事件カードは、UFO / UAP 史に関わる代表的な事件を短時間で理解し、関連人物・用語・形状へ移動できるようにするための辞典カードです。

事件の真偽を断定するのではなく、どの時代に、どこで、何が報告され、UFO文化や研究史の中でなぜ重要なのかを整理します。

## 一覧カード

一覧カードは、事件辞典の一覧や関連カードに表示する短いカードです。スマホで一目で読める情報量にします。

含める項目は次のとおりです。

- 事件名
- 英語名
- 年
- 場所
- 1行説明
- カテゴリ
- 関連タグ 2〜4個

一覧カードでは、詳細な経緯や長い解釈を入れません。事件が何で知られるかを優先します。

## 詳細カード

詳細カードは、事件詳細ページまたは展開表示で使う本文カードです。

含める項目は次のとおりです。

- 事件名
- 英語名
- 年月日
- 場所
- カテゴリ
- 30秒でわかる
- 何が起きたか
- 関連人物
- 関連用語
- 関連形状

すべての項目を必須にはしません。年月日や関連人物が不明な場合は、年、場所、代表的な関係だけを表示します。

## 本文の書き方

本文は、初心者にもわかる平易な日本語で書きます。

避けることは次のとおりです。

- 断定的に「本物」「嘘」と決めつける
- 陰謀論的な煽り
- 目撃者への嘲笑
- 信者的・崇拝的な書き方
- 長すぎる調査報告
- 専門用語だけの説明

重視することは次のとおりです。

- 何が報告されたのか
- 事件がUFO史でなぜ重要なのか
- 関連する人物・用語・形状への導線
- 説明や評価が分かれる場合は中立的に扱う
- 古典UFO、現代UAP、日本UFO史の文脈を混同しない

## カテゴリ

事件カードには、次のカテゴリを使います。

- 空飛ぶ円盤ブーム・初期UFO史
- コンタクティ文化
- アブダクションと体験談
- ハイストレンジネス
- UFOウェーブ・集団目撃
- 政府・軍・現代UAP
- 日本UFO史

## 関連タグ

関連タグは、用語辞典・人物辞典・形状辞典・他プロダクトへの接続に使います。

タグ例は次のとおりです。

- UFO
- UAP
- 空飛ぶ円盤
- コンタクティ
- アブダクション
- ハイストレンジネス
- UFOウェーブ
- 近接遭遇
- 着陸痕
- EM効果
- 検証
- 政府・軍
- 日本UFO史
- 現代UAP
