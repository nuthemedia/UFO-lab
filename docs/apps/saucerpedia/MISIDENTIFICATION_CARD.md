# saucerpedia Misidentification Card

## 目的

saucerpedia の「UFOと誤認」カードは、UFO / UAP として報告されやすい既知の対象や見え方を整理し、初心者が「何に見えるとUFOに感じるのか」「どう見分けるのか」を短時間で理解できるようにするためのカードです。

目撃者を否定するためのカードではありません。UFO調査では、既知の説明を丁寧に確認することで、本当に未確認として残る報告を見分けやすくします。

## 一覧カード

一覧カードは、誤認されやすい対象をざっと確認するための短いカードです。

含める項目は次のとおりです。

- 名称
- 英語名 / 別名
- カテゴリ: UFOと誤認
- 種類: 天体 / 航空機 / 生物 / カメラ由来 / 錯覚
- 1行説明
- 関連タグ 2〜4個

一覧カードでは、細かい検証手順を入れすぎません。何がUFOに見えやすいのかを優先します。

## 詳細カード

詳細カードは、誤認の理由と見分け方を理解するための本文カードです。

含める項目は次のとおりです。

- 名称
- 英語名 / 別名
- カテゴリ
- 種類
- 30秒でわかる
- なぜUFOに見えるのか
- 見分けるポイント
- よくある見え方
- 関連用語

すべての項目を必須にはしません。対象によって不要な情報は表示しません。

## 種類

初期実装では、次の種類を使います。

- 天体
- 航空機
- 生物
- カメラ由来
- 錯覚

## 書き方

- 「見間違いだから価値がない」と書かない
- 目撃者を嘲笑しない
- 断定よりも確認方法を示す
- 肉眼、写真、動画、センサーで見え方が違うことを意識する
- 関連用語として `誤認`、`IFO`、`検証` へ接続する
