# Jacques Project

Jacques v0.5 は、異なる怪異現象のあいだに見られる共通モチーフや構造を発見し、それらの関係を可視化するための知識探索アプリです。

## Purpose

Jacques は、ジャック・ヴァレが投げかけた問いを出発点にします。
UFO、妖精譚、神隠し、妖怪、宗教的幻視、コンタクティ体験といった現象は、本当にそれぞれ別個のものとして理解すべきなのか。それとも、そのあいだには繰り返し現れる共通構造があるのか。

本アプリは、異なる怪異が同一の現象であると主張するものではありません。
目的は、異なる怪異カテゴリーのあいだにどのような類似性が見られるのかを探索し、その関係を比較と可視化によって理解しやすくすることです。

v0.5 では、Jacques の中核体験である
「異なる怪異同士のつながりを発見する」
体験を検証することを目的とします。

## Audience

- UFO・UAP に興味のある人
- 妖怪、民俗学、伝承に興味のある人
- ハイストレンジネス研究者や読者
- Jacques Vallée の読者
- データ可視化や知識探索に興味のある人

## MVP Scope

- Jacques Vallée 的な問題提起に基づいた、少数の厳選比較事例を提示する
- 教育モードで、実際に比較可能な事例ペアを紹介し、なぜそれらが関連づけられるのかを説明する
- 探索モードで、ユーザーが UFO 事件カードを起点に、他ジャンルの怪異カードとのつながりを見られるようにする
- 各比較において、共通モチーフを表示する
- 想定するモチーフ例:
  小柄な存在、塩、食べ物、光、時間喪失、連れ去り
- 各カードには、比較に必要な最小限の情報を持たせる
- 収録項目:
  事件名、年代、場所、概要、画像、出典、モチーフ
- MVP で扱うジャンルは限定する
- 対象ジャンル:
  UFO事件、妖精譚、神隠し、妖怪、宗教的幻視
- 体験の最後に、Jacques Vallée の問いを想起させる導線を置く
- 例:
  「それらは本当に別々の現象なのだろうか？」

## Out Of Scope

- 異なる怪異カテゴリーが客観的に同一現象であると断定すること
- 大規模なユーザー投稿機能やオープンな共同編集
- コミュニティ評価によるグラフ線の強弱反映
- あらゆる怪異伝承を網羅する大規模データベース化
- 学術的証明や最終的な分類体系の提示
- ソーシャル機能、アカウント機能、パーソナライズ
