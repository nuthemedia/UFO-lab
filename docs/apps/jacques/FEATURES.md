# Jacques Features

## Core Features

- カテゴリチップでカードを絞り込む。
- 初期表示では横スクロールのカードセレクターから起点カードを選ぶ。
- PC初期表示では左右矢印ナビでカードセレクターを横に動かせる。
- カード選択後はセレクターを消し、上段の選択カードと下段の関連カード群へ切り替える。
- `connections` 配列から `fromCardId` または `toCardId` が一致する関連カードを抽出する。
- `adopt` 相当の接続だけを表示し、`displayMode: hidden` と `connectionShape: graph_only` は表示しない。
- `relationBasis`、`needsVerification`、`connectionShape` はデータとして保持するが、2段ビューの関連カード上部には表示しない。
- `cautionLevel` と `skepticNote` はデータとして保持するが、通常のカード詳細には注意ブロックとして表示しない。
- 選択カードと関連カードのあいだに、接続数ぶんの直接線を表示する。1対1接続では中央揃えの直線にする。
- `sharedMotifs` に含まれるモチーフを、選択カードと関連カード内で同名同期の発光アニメーション付きで表示する。
- `cluster` と `motif_group` は管理ラベルを出さず、下段の関連カード群として統一表示する。
- 2段ビューの上段カードもタップで開閉できる。
- 関連カードの閉じた状態では、事件名、接続タイトル、類似ラベルだけを表示する。
- 関連カードを選ぶと、詳細をカード内で折りたたみ展開し、もう一度選ぶと閉じる。
- 展開された関連カード内には、関連するWikiリンクを表示する。
- 緑ベースで目立つ「カードを選び直す」導線で選択カードと展開中接続を解除し、セレクターへ戻る。
- XでURLを共有したとき、Jacques専用の黒地・白シルエットの共有カードを表示する。
- Jacques 専用の黒地・白シルエットのファビコンを表示する。
- 画面下部に `UFO Lab Tokyo` ブランドリンクと控えめなコピーライトを表示する。

## User Flow

1. ユーザーは `/jacques` を開き、暗色の初期カードセレクターを見る。
2. 起点カードを選ぶ。
3. セレクターが消え、上段の選択カードから下段の関連カードへ線が伸びる。
4. 発光している共通モチーフを見て、つながりの理由を把握する。
5. 必要に応じて上段カードや関連カードを開き、カード内に展開される説明、Wikiリンク、信仰文脈注記を読む。
6. Jacques Vallée の問いを想起させる文を読み、別のカードへ戻る。

## States

- 初期状態: `UFO・空中現象` のカードセレクターが表示され、まだ探索ビューは出ない。
- 選択状態: セレクターが消え、選択カードと関連カードが2段構成で表示される。
- 関連なし状態: 該当接続がない場合、別カテゴリや別カードを選ぶ導線を表示する。
- 詳細表示状態: 選択中の接続詳細を関連カード内で表示する。
- 上段詳細表示状態: 選択中の起点カード詳細を上段カード内で表示する。
- 注意状態: 展開時に必要な信仰文脈注記だけを明示する。
- 外部リンク状態: 展開された関連カードで Wiki リンクを別タブで開ける。

## Acceptance Criteria

- `/jacques` が表示され、初期カテゴリが `UFO・空中現象` になっている。
- 初期表示でカードセレクターのみが表示される。
- PC幅で左右矢印を押すと、カードセレクターが左右にスクロールする。
- カード選択でセレクターが消え、選択カードと関連カード群が2段構成で表示される。
- 接続数ぶんの直接線が表示される。
- 1対1接続では、接続線と下段カードが中央揃えで表示される。
- `sharedMotifs` が選択カードと関連カードの両方で同名同期の発光アニメーション表示される。
- 上段カードクリックでカード内詳細が展開され、再クリックで閉じる。
- 関連カードの閉じた状態が、事件名、接続タイトル、類似ラベル中心になっている。
- 関連カード上部に `ヴァレ明示`、`要原本確認`、`ペア`、`関連モチーフ` などの管理ラベルが表示されない。
- 関連カードクリックでカード内詳細が展開され、再クリックで閉じる。
- 展開カード内に Wiki リンクが表示される。
- X共有用の `summary_large_image` メタデータと共有カード画像が設定されている。
- Jacques 専用 favicon が設定されている。
- `faithContextNote` は、必要な接続の展開表示にだけ反映されている。
- 関連カード詳細に通常の注意ブロックや `注意メモ` が表示されない。
- ユーザーに不要な制作上の除外説明は表示されない。
- フッターに `UFO Lab Tokyo` リンクとコピーライトが表示される。
- `npm run build` が通る。
