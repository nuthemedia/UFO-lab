# Jacques Design

## UI Direction

Jacques v0.5 の UI は、黒い研究卓に資料カードを並べるような暗色探索ビューとして扱う。背景は黒に近い深色、カードは暗い資料カード、共通モチーフは深緑と琥珀の発光で見せる。

画面の主役は、選択カード、関連カード、直接接続線、発光する共通モチーフである。宗教的幻視や民間伝承は、それぞれの文脈を尊重し、「UFOだった」と読める表現を避ける。

## Screens

- `/jacques`: v0.5 UI モックの単一ページ。
- 上部: タイトル、短い説明、カテゴリチップ。
- 初期表示: 横スクロールのカードセレクターのみ。
- PC初期表示: 横スクロールのカードセレクターに左右矢印ナビを表示し、カード列を操作できるようにする。
- 探索表示: カード選択後、セレクターは消え、上段に選択カード、下段に関連カード群を表示する。
- 接続表示: 選択カードと関連カードの間には説明ブロックを挟まず、直接の線を表示する。複数接続があれば線も複数出す。1対1接続では、上段カード中央から下段カード中央へ直線でつなぐ。
- 上段カード: 2段ビューでは上段カードもタップで開閉でき、開いた時だけ詳細説明とWikiリンクを表示する。
- 詳細表示: 関連カードを選ぶと、カード内で接続説明、信仰文脈の注記、最後の問いを折りたたみ表示する。通常の注意ブロックは本文途中に挟まない。
- 圧縮カード: 関連カードの閉じた状態では、事件名、接続タイトル、類似ラベルだけを表示する。
- 関連カード: 関連カード上部には根拠種別や接続形状の管理ラベルを出さず、共通モチーフの発光ラベルを主役にする。
- 展開カード: 関連カードをクリックすると、理由、注意文、Wikiリンクをカード内で表示する。再クリックで閉じる。
- 共有カード: XやOGPで表示される画像は、黒地にジャック・ヴァレを想起させる白いシルエットだけの最小構成にする。
- ファビコン: Jacques 専用のアイコンは、共有カードと同じく黒地に白いシルエットだけの最小構成にする。
- フッター: 画面下部に `UFO Lab Tokyo` へのブランドリンクと控えめなコピーライトを中央寄せで置く。

## Responsive Behavior

スマホ優先で設計する。初期カードセレクターは横スクロール、探索表示の関連カードは縦積みを基本にする。スマホでは選択カード、接続線、複数の圧縮カードがなるべく少ないスクロール量で見えることを優先する。広い画面では下段の関連カードを複数カラムにし、選択カードから各関連カードへ扇状に線を伸ばす。

テキストはカード内で折り返し、バッジやチップが横幅を押し広げないようにする。画像がないカードには、カテゴリ別のプレースホルダーを表示する。

## Motion And Effects

Motion を使い、カードセレクターの退場、選択カードの上段配置、関連カードのフェードイン、接続線の描画、カード内詳細の展開を入れる。動きは状態変化の理解を助ける範囲に留め、`prefers-reduced-motion` では短いフェードまたは即時表示にする。

接続線は D3 や本格グラフではなく、軽量な SVG/CSS で表現する。

選択カードと関連カードの共通モチーフラベルには、同じモチーフ名が上下で同じタイミングで光る弱い発光アニメーションを入れる。
